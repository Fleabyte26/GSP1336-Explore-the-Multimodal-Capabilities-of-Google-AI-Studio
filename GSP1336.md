# GSP1336 - Multimodal prompting and a robotics app in Google AI Studio

This lab has no Cloud Shell. Tasks 1 and 2 are done in Playground, Tasks 3 and 4 in BUILD > Gallery. The prompts and names to type are in copy blocks. After every Run, wait until the answer has finished, then save with the exact name given: the checker reads your saved prompts.

## Known lab traps/bugs (read first)

1. Wrong account. Open AI Studio in the Incognito window with the lab's student account.
2. Paid models. If the model the lab names has a "Paid" badge in the model list, the student account cannot use it (you get an "Unlock ..." screen with an Upgrade button, or a window titled "Go further with AI Studio"). Never click Upgrade and never set up billing. Close the window and pick a model without the badge. In lab GSP1335 the checker accepted a free model in place of the paid one the lab named.
3. The Drive pop-up on your first Run is not optional. Click Enable Google Drive, pick the student account and allow. Without it nothing is saved and the checks fail.
4. Save names must match exactly: Futuristic Museum Lobby, Museum Exhibit Highlights, Robotics Spatial Understanding.
5. Nothing extra in the prompt box. Before you click Run, make sure no stray file or screenshot is attached under the prompt (remove it with its X). Task 2 is the only one that needs an attachment, the sample video.
6. A red message about not having permission to generate API keys can pop up. Close it and carry on.
7. The checker lags. If a check fails, wait 30-60 seconds and click again.

## Task 1. Generate images

1. In the left menu click Playground.
2. On the right, under Run settings, click the model card. Open the Gemini tab and pick the model the lab names for Task 1 (see trap 2 if it is paid).
3. Paste this prompt and click Run:

```text
A photorealistic image of a futuristic natural history museum lobby, with a giant T-Rex skeleton made of glowing blue crystals.
```

4. In the pop-up, click Enable Google Drive, pick the student account and allow.
5. When the answer is done, click the edit (pencil) icon next to the chat title. For Prompt name type exactly this, then click Save:

```text
Futuristic Museum Lobby
```

You should see a generated image of the museum lobby. If the only models you can use answer with text and no image, save anyway and try the check.

## Task 2. Analyze a long video

1. In the left menu click Playground again so you get a new, empty chat.
2. Click the model card, open the Gemini tab and pick the model the lab names for Task 2. It is a different model from Task 1 (see trap 2 if it is paid).
3. In the prompt bar click the attachment icon (a plus sign in a circle) and choose Sample Media.
4. Pick American Museum of Natural History Tour - 10 Min and click Add to prompt. Wait until the video shows a token count.
5. Paste this prompt and click Run. It takes a while, the model is reading the whole video:

```text
Please provide a summary of the main exhibits shown in this video tour. List each distinct hall or section and give a one-sentence description of each.
```

6. When the answer is done, click the edit (pencil) icon next to the chat title. For Prompt name type exactly this, then click Save:

```text
Museum Exhibit Highlights
```

You should see a list of museum halls with one sentence each.

## Task 3. Build the robotics app from a template

1. In the left menu, under BUILD, click Gallery.
2. Find the card Robotics Spatial Understanding. If you do not see it, select All apps to show the full gallery.
3. Click the card. The app opens with its code and a live Preview.

## Task 4. Try the app and change it (no check button in the lab text)

Try it:

1. In the Preview, click the sample image at the bottom that shows mangos.
2. Make sure 2D bounding boxes is selected. In the PROMPT box type the word below and click Send. Boxes appear around the mangos.

```text
mango
```

3. Select Points and click Send. Dots appear on the mangos.

Change it with the Code assistant:

4. Select 2D bounding boxes again.
5. In the Code assistant field at the bottom left ("Make changes, add new features...") paste:

```text
Make the bounding boxes red.
```

6. Click Remix (or the assistant's Send button, then Remix app). A new browser window opens: click Acknowledge and wait while the assistant rewrites the code.
7. Back in the Preview, with the mango image and 2D bounding boxes selected, click Send for mango once more. The boxes should now be red.
8. Click the edit (pencil) icon next to the app title. For the name type exactly this, then click Save:

```text
Robotics Spatial Understanding
```

If the Preview cannot detect anything because of the API key message (trap 6), do steps 5 to 8 anyway so the changed app is saved.
